## ✨ Features

- **Light/Dark Mode Toggle** — switch between light and dark modes from the navigation

- **Project Filtering** — filter by category (All, Desktop, Web, Backend, Analytics)
- **Live Demo + GitHub links** — each project card links to both a working demo (where deployed) and its source repo
- **Experience Timeline** — work history at a glance
- **Smooth Scrolling & Animations** — fade-in effects and smooth section navigation
